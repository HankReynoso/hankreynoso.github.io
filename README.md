# hankreynoso.github.io

Hank Reynoso's portfolio and app pages, published with GitHub Pages.

- Home page (`index.html`, styled by `assets/portfolio.css`): projects, education, skills and contact.
- [Price Tracker demo](https://hankreynoso.github.io/price-tracker/): the Price Tracker's page running in the browser. `demo-backend.js` stands in for the Python server with sample prices and localStorage; the other files are copied from the [Price-Tracker](https://github.com/HankReynoso/Price-Tracker) repo's `public/` folder.
- [Gains](https://hankreynoso.github.io/gains/) and its [Privacy Policy](https://hankreynoso.github.io/gains/privacy/), styled by `assets/site.css`. The policy is kept in step with the Gains Privacy Policy doc.
